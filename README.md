Employee Productivity Analysis and Turnover Prediction

📌 Overview
This project focuses on analyzing employee productivity metrics and predicting company turnover using machine learning techniques. By combining productivity factors and company financial indicators, the project helps businesses make data-driven decisions to optimize workforce efficiency and reduce employee attrition.

🎯 Objectives
- Analyze key productivity factors such as incentives, working hours, overtime, idle time, and break time.
- Predict employee turnover using classification models.
- Identify patterns that impact productivity and revenue.
- Help organizations improve workforce management and retention strategies.

🧠 Technologies & Tools
- Python
- Pandas, NumPy, Matplotlib, Seaborn (EDA & Visualization)
- Scikit-learn (ML Models)
- Jupyter Notebook / VS Code

📊 Machine Learning Models Used
- Decision Tree – for transparent, rule-based predictions.
- Random Forest – for improved accuracy and generalization.
- Logistic Regression – for probabilistic insights into employee turnover.

📈 Key Results
- Achieved up to 96% accuracy in turnover prediction using Random Forest.
- Identified critical productivity drivers such as overtime and idle time.
- Developed a scalable and interpretable system for HR analytics.

📄 How to Run

2. Navigate to the project folder: cd employee-productivity-turnover
3. Install required libraries : pip install -r requirements.txt
4. Run the Jupyter notebook: jupyter notebook
